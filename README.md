
# Smart Business Accounting System

A cross-platform business accounting application inspired by
modern accounting software such as QuickBooks.

## Project Overview

The system allows individual business owners to manage:

- Income
- Expenses
- Customers
- Invoices
- Financial Reports
- Business Analytics
- Basic Financial Forecasting

## Platforms

- Android Application
- Web Application

## Technology Stack

### Frontend
- Flutter
- Dart

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL

### Authentication
- Firebase Authentication

### Development Tools
- Visual Studio Code
- Git
- GitHub

## Architecture

Flutter Applications
        |
        v
Express REST API
        |
        v
PostgreSQL Database

Firebase Authentication handles user identity.

## Main Features

1. User Authentication
2. Financial Dashboard
3. Income Management
4. Expense Management
5. Customer Management
6. Invoice Management
7. Excel Import
8. Financial Reports
9. Business Analytics
10. Moving Average Forecasting

## Security

- Firebase-based authentication
- Email verification
- Unique usernames
- User-specific database records
- Backend authorization
- Environment-based secret management
